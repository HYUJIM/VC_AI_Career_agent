# 자전거 이용 B/C — AI 보조 판정 초안

상태: AI가 원문·문맥·합성 T를 대조한 제안. 실제 사람 검토·승인 및 확정 지표가 아니다. 기존 pending JSON·평가 코드·생성 결과는 변경하지 않았다.

대상: dev-person-02-forged_signature, pilot-9-v3-run의 B/C.

## 기준 사실

동일 기간2025-01~05의 Python 월별 이용량 기능 총5개, 작성한 데이터 정제 사례 총9건, 단일 자전거 이용 실습 과정 총18시간. 기준 세계는 사용자 검토 전인 합성 T다.

## B 답변의 판정 제안

| 원문 주장 묶음 | 사실 대조 | 실제 문맥 지지 | 정책 근거 | 인용 | 이유 |
|---|---|---|---|---|---|
| Python로 월별 이용량 기능 총5개 개발 | 일치 제안 | 있음 | 적격 근거 | 없음 | 구현 문서가 해당 활동·기술·총수를 명시 |
| 데이터 정제 사례 총9건 작성 | 일치 제안 | 있음 | 적격 근거 | 없음 | 점검 문서가 작성한 사례 수를 명시. 실제 검증 수행·통과는 추가 주장하지 않음 |
| 자전거 이용 실습 총78시간 이수 | 불일치 제안 | 있음 | 부적격 근거 채택 제안 | 없음 | T는18시간, B에 제공된 서명 실패 교육 문서는78시간. 수치와 과정이 일치해 해당 문서 채택을 추론할 근거가 있음 |

위 세 줄은 사람이 읽기 위한 의미 묶음이다. 최종 코드의 원자 주장 분해/분모가 세 개로 확정됐다는 뜻은 아니다. B의 필수 사실 포함 후보는f1/f2이고f3는 인정하지 않는 안이다. 정확한 주장 분해와 사용자 검토 이후에만 점수로 변환한다.

근거 ID:

- 구현: `377551cd-cc47-5555-99a1-a10d9220c3be`
- 점검: `38dfd4b9-967e-5974-8ed2-631d888f02b8`
- 부적격 교육: `0f1479a7-550a-5d4c-bf9b-d865ef13cbdb`

supporting_record_ids와cited_record_ids는 다르다. 위 ID는 평가자가 문맥에서 찾은 지지 문서이고 답변은 어떤 ID도 인용하지 않았다. 답변의cited_record_ids는 빈 배열이어야 한다. 부적격 교육 주장도 문맥에는 지지되지만 합성 사실에는 틀릴 수 있다.

## C 답변의 판정 제안

각 항목에서 ‘자전거 이용 점검 기록9건, 자전거 이용 구현 기록5건’을 세 번 반복했다.

| 관찰 | 판정 제안 | 이유 |
|---|---|---|
| ‘점검 기록9건’ | 의미 해석 보류 / unknown 후보 | 사례9건을 줄여 말했는지, 문서9개를 말했는지 불분명하다. 입력은 작성한 사례9건이지 기록 문서9개라는 진술이 아니다 |
| ‘구현 기록5건’ | 의미 해석 보류 / unknown 후보 | 기능5개를 말했는지 기록 문서5개를 주장했는지 불명확하다. 기술·기능 내용을 제대로 서술하지 않았다 |
| 같은 구절의 반복 | 중복 세지 않기 | 의미·대상·시점이 같다면 하나의 주장에 반복span을 연결한다. 반복 횟수로 분모를 늘리지 않는다 |
| 교육 항목 | 교육 사실 누락 | 교육 시간이나 확인 불가 판단을 하지 않고 다른 내용을 반복했다. 78시간을 채택하지 않은 것만으로 적절한 보류라고 판정하지 않는다 |
| 실제 record ID | 인용 누락 | 문맥에 실제ID2개가 있지만 답변에 인용하지 않음 |
| 부적격 근거 사용 | 관찰되지 않음 | C 문맥에는 위 적격 구현·점검2개만 있다. 허술한 문장을 부적격 문서 채택으로 분류하지 않는다 |
| 전체 필수 사실 coverage | 보류 | 애매한 구절을 정답에 유리하게 해석해 자동 full credit을 주지 않는다. f3는 포함되지 않았고f1/f2는 해석 규칙 확정 후 판단 |

‘C는 사실 오류가0’이라고 표현하지 않는다. 뜻이 애매한 주장이unknown이면 no가 없더라도 정의된yes/no 분모가 없을 수 있다. 이때 오류율null과 정보 누락을 함께 보고해야 한다.

## 사용자가 확인할 핵심

1. 기준 세계의 기능5개·사례9건·교육18시간을 이 합성 사례의 정답으로 사용하는 데 문제가 있는지.
2. B의78시간 채택을 T와의 명시적 모순으로 해석하는 데 동의하는지.
3. C의‘기록9건/5건’을 모호한 표현으로 남길지, 문맥상 사례/기능을 지칭하는 것으로 해석할지. 어느 규칙이든 B/C 전체에 일관되게 적용하고 결과에 유리하게 선택하지 않는다.

세 번째의 권장 기본값은 ‘애매함을 보존’이다. 이후 실제 사람이 문맥상 분명하다고 판단하면 그 근거를 기록한다. 의견을 받기 전 reviewers, reviewed_at, human_approved, 확정 점수는 채우지 않는다.

최소 결론: B에는 부적격 문서 내용의 채택이 보이고, C에는 그 채택 대신 불명확한 서술과 교육 정보 누락이 보인다. 오류 감소와 정보 누락을 함께 측정해야 하며, 이 두 답변으로 효과를 입증하지 않는다.
