# BE 연결용 합성 예제

`careers_response.json`은 현재 BE careers 응답 형식으로 직접 만든 테스트 예제입니다.
기업의 실제 발급 데이터나 실제 암호학적 검증 결과가 아닙니다.

- 프로필 1명: `did:example:be-demo-001`.
- 배지 4건: BE 표시 verified 2건, revoked 1건, 알 수 없는 상태 1건.
- 예상 변환: 수신 4 / 채택 3 / 격리 1.
- `question.txt`는 연결 확인용 질문이며 정답·평가셋이 아닙니다.

실행법은 `ai/BACKEND_INTEGRATION.md`를 참고하세요.
